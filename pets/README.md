# Pets

This directory contains the downloadable Codex v2 pets.

Each subdirectory is a complete pet:

```text
<pet-id>/
├── pet.json
├── spritesheet.png
└── spritesheet.webp
```

Copy a folder into `~/.codex/pets/` to install it. See [docs/INSTALLATION.md](../docs/INSTALLATION.md).
