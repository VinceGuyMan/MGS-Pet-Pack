MGS1-Pet-Pack

A public collection skeleton for Codex/OpenPets-compatible desktop pets discovered on the local machine. NOTE: This repository intentionally does NOT include the actual pet asset files from the owner's machine because the discovered pets are third-party Metal Gear Solid characters (copyrighted). Instead this repo documents the collection, provides installation instructions, and explains how to add your own local pet folders.

Included (metadata only)

- Inventory of discovered pets (INVENTORY.md)
- Installation instructions (docs/INSTALLATION.md)
- CONTRIBUTING guidelines
- pets/ directory (placeholders — assets are intentionally omitted)

Compatibility

- The discovered pet manifests use `spriteVersionNumber: 2` (Codex v2). This repo provides guidance for installing those pets into `~/.codex/pets/` on your machine.

How this repo was produced

- The live pet directory inspected: `~/.codex/pets`
- No files were modified.
- All discovered pets appear to be third-party copyrighted characters and so their asset files were not copied into this public repository.
